# Headroom - Tema One

Usare la configurazione Headroom comune del progetto quando si lavora sul tema One.

## Comandi

```bash
headroom mcp status
headroom doctor
headroom savings
headroom perf --hours 24
```

- Config canonica: `../../../../../.headroom.yaml`.
