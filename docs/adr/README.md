# ADR — Theme One

Un ADR del tema One registra una scelta difficile da invertire, sorprendente o frutto di un trade-off reale su struttura del tema e build degli asset. Ogni affermazione ha un file di prova. Template condiviso: [0000-template](../../../../Modules/Xot/docs/adr/0000-template.md).

## Formato MADR

Frontmatter (`title`, `type: decision`, `status`, `created`, `updated`, `decision-makers`, `module`, `qmd`) e sezioni nell'ordine: `## Contesto`, `## Driver della decisione`, `## Alternative scartate`, `## Decisione`, `## Conseguenze`, `## Conferma`. Nome file in kebab-case senza data né numero.
